# Logo SmartLot — modelo de alta

- `logo-smartlot-alta.glb`: dos mallas (`P` y `Flecha`), 1 m de alto, 14 cm de profundidad, bisel suave, material PBR azul `--color-brand-blue` con clearcoat. Datos en `modelo.json`.
- `render-*.png`: renders 1600 × 1600 (frente, tres cuartos, perfil y fondo oscuro).

No se usa en la web (la landing usa la versión liviana generada en el navegador). Se regenera con los scripts de `scripts/logo3d/`; ver `docs/logo-3d.md`.
